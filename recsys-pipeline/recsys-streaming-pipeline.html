Data Pipeline — Kafka + Spark Streaming

  • • producer.py: clickstream (user_events) + behavior mode (behavior_logs, request_id-keyed slates)
  • • UserEventStreamingJob: per-executor JedisPool → LPUSH+LTRIM+EXPIRE per user, ZINCRBY per item
  • • OnlineJoinerStreamingJob: single-pass conditional groupBy → labeled samples (label 0/1/2); Parquet date-partitioned
  • • ExperienceCollectorStreamingJob: item samples → slate JSON (position-sorted, aggregate reward)
  • • RecommendationResponseStatsJob: response metrics → recommendation_metrics topic (type/subscription/country/blender tags)
  • • MovieLensContextCollectorStreamingJob: user/{movie features → Redis hashes TTL=30d

Java Retrieval Service — 9-Step Request Flow

  • • 21 QueryHydrator impls: demographics, gender inference, action sequences, social graph, bloom filter, MinHash, geo, served history, cached movies, followed genres/collections
  • • 10 CandidateFilter impls: bloom/seen, served, self, blocklist, muted keywords/genres, age, video, reshare-dedup, newUser-genre
  • • 13 CandidateHydrator impls: title/genres, in-network, Jaccard, engagement counts, subscription, language, blocked-by, visibility, social proximity, safety signal
  • • 3-layer scoring: offlineScore (cosine+content+popularity+ONNX) → learnedPrior → banditScore (UCB|Thompson|Q|SARSA)
  • • FeatureCache (Caffeine): pre-MGET before loop; item-vector TTL=300s; reward TTL=30s; immediate invalidation on /feedback
  • • Endpoints: /recommend · /predict/{user}/{item} · /predict/id · /predict/metadata · /embedding/{item} · /feedback · /metrics

Experiment Pipeline — Bandit + Retrain Loop

  • • UCB: Beta posterior mean + sqrt(log(N)/pulls) confidence bonus; Thompson: Beta(α,β) sample per arm
  • • Q-learning: tabular Q-values in Redis (q-learning:q:{state}), Bellman update on /feedback
  • • SARSA: on-policy variant (sarsa:q:{state}), epsilon-greedy policy for both serve + update
  • • /feedback: 3-phase pipelined write (1 round-trip vs ~22); HINCRBY bandit+reward; RPUSH replay buffer; local cache invalidation
  • • run-retrain.sh: 5-stage cron (0 */6 * * *): replay export → Spark ALS → UserEmb → Python two-tower → POST /actuator/model-reload
  • • Cold-start RL roadmap: Q-learning → DQN → Double DQN → Dyna-Q (simulated experience for new items)
